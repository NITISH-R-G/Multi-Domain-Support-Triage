# Security Policy

## Supported Versions

The following versions of HackerRank Orchestrate are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report (suspected) security vulnerabilities to security@example.com. You will receive a response from us within 48 hours. If the issue is confirmed, we will release a patch as soon as possible depending on complexity but historically within a few days.

Please do NOT create an issue for a security vulnerability, as it might expose it to the public before a fix can be prepared.
